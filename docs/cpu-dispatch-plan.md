# CPU 디코드: 디스패치 구조 계획

2026-09-20 밤 기준. 근거 수치는 rig-log `log/2026-09-20-j-*`와 `-k-*`다. 이 문서는 계획이고, 잰 것만 "잰 것"이라 쓴다.

## 산수

스텝 13.8 ms(N=96, 72.30 tok/s). ik는 같은 임대에서 12.2 ms(tg32 81.79).

~~"내적은 완전 병렬일 때 8.3 ms이고 ik의 스텝 전체보다 짧으니 나머지 7.5 ms만 줄이면 된다."~~ 선 그음: ik를 perf로 보니 ik의 커널 스레드시간이 스텝당 약 290 ms(12.1 ms × 32 × 0.75)이고 우리 dot 열의 합은 266 ms다. 커널은 같은 선이고, dot/32는 도달 가능한 이상치가 아니라 이용률 100%라는 가정이다. 다른 것은 **워커 이용률 — ik 75%, 우리 51%** — 이고, 워커가 노는 시간은 메인 스레드가 디스패치 사이에 혼자 일하는 시간이다.

메인 스레드의 정상 상태(perf `cpu-clock`, 해체 구간 제외): 디스패치 안 53%, `memset` 13.5%, malloc·free 계열 12.5%, swiglu+`expf` 8.4%. 직렬 구간의 절반이 할당과 0 채우기였고, 스텝당 할당자 호출이 14454번이었다(`just gate-alloc`).

빈 클로저 디스패치는 4.65 µs다(풀 벤치). 단일 matmul 호출의 나머지 12.5 µs는 그 위에 입력 양자화, 호출당 Vec 여덟아홉 개, 장벽 대기가 얹힌 것이다. 디스패치 하나를 더 잘게 나누는 쪽(동적 행 분배, 폭 제한)은 둘 다 재서 기각했다.

## 단계

각 단계의 완료 조건은 같다: 비트 게이트 rc 0(재핀 없음 — 아래는 전부 계산을 옮기는 것이지 식을 바꾸지 않는다), 그리고 `just ab-decode`로 직전 커밋 대비 네 바퀴.

**0. 끝난 것.** swiglu를 8레인으로(`qdot::swiglu`, +4.0%) · `target-cpu=znver3`(+4.8%) · `Tensor2` 프리리스트와 `ok_or_else`(할당 14454 → 11463, 속도 무변화) · 스텝 플랜(아래 1, +9.6%, 할당 1291).

**1. 스텝 안에서 로드 시점의 일을 하지 않는다.** (끝 — 4d1b00e, 66.11 → 72.48) 텐서 조회와 이름 `format!`, `MlaParams`·`Meta`, norm gain 디코드, 헤드별 v_up 뷰와 전문가 뷰를 `Derived`에 한 번 만들어 두고 스텝은 읽기만 한다. `matmul_q_multi`의 호출당 Vec, 프로파일이 꺼졌을 때의 `ChunkSlots`, MoE 트레이스 채우기를 걷어낸다. 계약은 `gate-alloc` ≤ 1500.

~~**같은 입력을 한 번만 양자화한다(내용 비교).**~~ 재서 기각: 62.83 → 61.03 tok/s, 네 바퀴 모두 패. 같은 입력임을 *구조로* 아는 경우(아래 3의 묶음)만 남긴다.

**2. down 입력의 swiglu → quant를 워커로.** swiglu는 8레인이 된 뒤 메인 스레드에서 작아졌다. 1 뒤에 다시 재서 아직 보이면 down 배치의 컬럼 디스패치에 붙인다.

**3. 이종 묶음 디스패치 `matmul_q_group`.** 지금의 배치는 모든 쌍이 같은 (k, n, 타입)이어야 한다. 쌍마다 자기 타입·n·행 바이트를 갖게 하고 청크를 행 수가 아니라 **바이트**로 자르면 다음이 한 디스패치가 된다.

- attn: {q 투영, kv_a 투영} — 같은 x
- moe 앞: {라우터, shexp gate, shexp up} — 같은 ffn_norm
- moe 뒤: {라우팅 down × 6, shexp down}

입력 양자화는 (입력, 활성값 포맷) 쌍마다 한 번이다 — Q3_K는 q8_K, 나머지는 q8_2_x4라서 같은 x라도 포맷이 다르면 두 번 한다. 층당 디스패치 −4.

**4. wv_b_heads, q_nope2.** 1–3 뒤에 다시 잰다.

기대치는 적지 않는다. 단계마다 재고, 표를 이 문서가 아니라 rig-log에 쓴다.

## 하지 않는 것

- 디스패치 폭 제한, 동적 행 분배, malloc 임계, CPU 거버너 — 재서 기각(rig-log -j). 내용 기반 입력 중복 제거 — 재서 기각(-k).
- n-gram 추측 디코딩 — 이 프롬프트 집합에서 수용 1.19토큰/스텝 대 손익분기 1.39(MUL-43). 초안 모델·MTP는 k=4에서 2토큰/스텝이 기준선.
- 커널 재작성 — 커널 스레드시간은 이미 ik와 같은 선이다(266 대 ~290 ms/스텝).
