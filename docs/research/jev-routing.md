# "jev" 라우팅 유행 — 정체와 우리 엔진에 닿는 몫

2026-09-21. opus 조사, 원문은 [`jev-routing-report.md`](jev-routing-report.md). 리드가 원본에서 확인한 것: TechCrunch 기사(09-18), TypeSafe 모델 문서(요금·속도 제한), slo-router README의 p95 수치. 나머지 인용은 조사 보고만 읽었다.

## 정체

Jev는 TypeSafe AI(창업자 Diogo Almeida, 전 OpenAI)가 2026-09-15에 공개한 첫 모델이다. 언어 모델이 아니다 — 텍스트를 내지 않고 호출자가 정한 스키마 위의 **보정된 확률**을 낸다. 입력 10억 토큰당 42달러, 출력 토큰은 무료, 속도 제한은 "250,000 tokens per second / 1,200 requests per minute". MoE 전문가 라우팅과는 무관하고, 출시 주에 가장 많이 쓰인 자리는 **모델 라우터·분류기·판정자 안의 LLM 호출을 대체**하는 것이다. 며칠 안에 셀프호스트 복제(`featherless-ai/simple-jev` — 아무 오픈 모델의 다음 토큰 로짓을 라벨 토큰에서 읽어 결정으로 쓴다)가 나왔고, 한국어 커뮤니티에도 09-20 무렵 "70 ms 의사결정으로 채팅 모델보다 빠른 라우팅" 식의 글이 돈다.

## "tok/s가 확 올랐다"는 전제

영어·한국어 어느 소스에도 Jev가 어떤 모델의 **디코드 처리량**을 올렸다는 주장은 없다. 주장은 전부 **결정 하나의 지연과 비용**, 그리고 싼 모델로 더 많은 트래픽을 보내서 얻는 파이프라인 처리량이다. "250,000 tokens per second"는 벤더 문서의 **쿼터**다. 제3자 측정 둘은 오히려 반대로 나온다: slo-router는 로컬 결정 특징 대비 Jev를 끼우면 p95가 77.93 → 490.38 ms로 느려지고 경로·정확도는 같다(리드 확인); classmethod는 결정당 0.65 s(N=40)다. TypeSafe 자신도 배수를 "천장이지 측정될 값이 아니다"라고 한다. 조사가 못 찾은 것이 하나 있다 — tok/s를 문자 그대로 주장하는 원글. ~~**사용자가 본 글의 링크가 있으면 이 결론을 바꿀 수 있는 유일한 물건이다.**~~ 원글을 봤다(같은 날 저녁, 일본어 글의 표 캡처). 47,514토큰 프리픽스에 접미사 256~16,384를 붙이는 벤치에서 `full_prefill` 44.95~74.14 s 대 Jev가 고른 `reuse_gpu_slot` 1.05~1.13 s, "유효 처리량 45,500~63,100 tok/s, 최대 65.7배". 즉 **tok/s는 프리필 유효 처리량**(전체 토큰 ÷ 벽시계)이고 이득은 전부 **GPU에 남아 있는 KV 슬롯 재사용**에서 온다 — Jev는 셋(전체 프리필 / 호스트 스냅샷 블록 재생 256·512 / 슬롯 재사용) 중 하나를 confidence 0.99~1.00으로 고르는 자리다. 그 선택은 '캐시 적중이면 재사용'이라는 결정적 규칙 하나와 같고, Jev의 API 판정 시간이 1 s 안에 들어 있다. 디코드 tok/s와 무관하다는 결론은 그대로다. 표 안의 이상값(`block256` 접미사 16,384에서 99.63 s로 전체 프리필보다 느림)은 그 글이 설명하지 않는다.

## 우리 상자에 닿는 몫

엔진 층에는 0이다. 이 유행의 어떤 항목도 요청 경계 아래에서 돌지 않는다. 전문가 라우팅 예측·캐시·지연 실행은 [`hybrid.md`](hybrid.md)가 이미 숫자로 묶었다.

닿는 자리는 서빙 층 `plan.md`의 4단계 "빠른/느린 모델 라우팅"이다. 그 다섯 글자는 (b) 범주 전체이고 판정 기준이 없다. 이 유행이 남기는 것은 그 행을 판정 가능하게 하는 조건 하나 — **결정은 로컬이고 1 ms 아래여야 한다**(이미 올리는 드래프트 모델의 로짓 읽기, 또는 DeBERTa급 인코더). 네트워크 호출은 그것이 아끼는 것보다 비쌀 수 있다는 것이 slo-router의 수치다.

판정 측정은 GPU 없이 한 번이다: 고정 프롬프트 32개 + 실제 트래픽에서 **DSpark 드래프트 혼자 답해도 되는 비율 φ**를 재고, 전체 토큰 ÷ 전체 시간으로 T_eff를 계산해 정확 경로(드래프트+검증)의 22.8 tok/s와 비교한다. 못 넘으면 (b) 범주는 이 상자에서 닫힌다 — 이미 공짜로 있는 처리량을 품질로 사는 셈이기 때문이다.

곁가지 하나: `simple-jev`의 로짓 읽기는 라우터가 아니라 **싼 평가기**로 쓸 만하다. 출력이 바뀌는 변경(Expert Deferral 등) 뒤에 "답이 여전히 받아들일 만한가"를 판정 모델 없이 묻는 게이트 도구다.
