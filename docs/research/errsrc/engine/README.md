# 엔진 팔의 위치별 마진 (2026-09-22 저녁)

`gate_e2e --margins`가 쓴 교사 강제 1056위치의 마진이다. 카드는 3090(게이트 카드), 트리는 main `f1fe77b`.
`scalar.tsv`는 `BLOOMERY_FLASH_MMA=0`, `mma.tsv`는 텐서 코어 패스다. 정확성 실행이라 카드는 수치에 영향이 없지만
조건으로 적어 둔다.

`cmp-mma-scalar.out`은 `tools/errsrc-cmp-engine.py engine sim`의 출력이다. 두 엔진 팔을 f64 참값(`sim/f64`)과
우리 반올림 규칙의 시뮬(`sim/ours`)에 위치마다 대고, 차의 RMS와 꼬리 개수를 가우시안 기대와 나란히 찍는다.
MMA를 기본값으로 켤지 이 표로 판정했다. MMA가 자기 규칙 시뮬에서 떨어진 거리(RMS 0.310)는 스칼라(0.332)보다
크지 않고, 꼬리도 스칼라보다 두껍지 않다. 꼬리는 어느 쌍에서나 가우시안보다 훨씬 두껍다. 시뮬 대 참값도
마찬가지라서, 이 꼬리는 MMA가 아니라 오차 분포 자체의 성질이다.
